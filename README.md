
# 🌾 SevaMitra — Autonomous Ration Service Resolver

> **An AI agent that doesn't just answer citizen queries — it investigates, acts, and resolves ration-service issues.**

SevaMitra is an AI-powered citizen assistance system designed for **Fair Price Shop (FPS) / ration distribution services**.

The system combines **Face Verification, OTP Authentication, ration eligibility verification, intelligent slot management, and autonomous issue resolution** into a single agent-driven workflow.

Instead of forcing citizens to navigate multiple steps manually, the SevaMitra Agent understands their problem, investigates the relevant information, performs the required actions through tools, verifies the outcome, and closes the issue.

---

## 🎯 Problem Statement

Government ration distribution often requires citizens to:

* Complete identity/biometric verification
* Verify their registered mobile number using OTP
* Check their ration entitlement
* Visit their assigned Fair Price Shop
* Wait in long queues
* Manage collection slots
* Handle missed or cancelled appointments
